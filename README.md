Financial Performance Dashboard (Power BI)
📌 Project Overview
This project is a Financial Performance Dashboard developed using Microsoft Power BI. The dashboard provides a comprehensive view of sales, profit, units sold, and performance analysis across segments, countries, products, and months. It helps stakeholders quickly understand business performance and make data‑driven decisions.

🎯 Objectives
Analyze total sales, profit, and units sold
Compare performance across business segments
Track monthly trends in profit and units sold
Identify top‑performing countries and products
Enable interactive filtering and drill‑through analysis

🧰 Tools & Technologies Used
Microsoft Power BI Desktop
DAX (Data Analysis Expressions)
Power Query for data cleaning and transformation
Excel / CSV Dataset (Financial data)

📊 Dashboard Pages & Insights
🔹 Page 1: Financial Performance Overview

KPI Cards:
Total Profit (2.10M)
Total Sales (15.36M)
Count of Sales (92)

Bar Chart: Sum of Profit by Segment (Government, Small Business, Midmarket, etc.)
Donut Chart: Sales distribution by Country
Line Chart: Count of Units Sold by Month
Product Slicer: Interactive product‑wise filtering
Country Highlight: Dynamic country selection (e.g., Canada)

🔹 Page 2: Detailed Profit & Sales Analysis

Horizontal Bar Chart: Monthly Profit Analysis
Pie Chart: Profit Contribution by Segment
Donut Chart: Sales by Segment
Country Slicer: Filter dashboard by selected country

🔍 Key Insights

Government and Small Business segments contribute the highest sales and profit
October and December show peak profit months
Canada and USA are major revenue‑generating countries
Sales distribution varies significantly across segments and regions

🧹 Data Cleaning & Modeling

Removed duplicate records
Handled null/missing values
Created calculated measures using DAX
Optimized relationships between tables
